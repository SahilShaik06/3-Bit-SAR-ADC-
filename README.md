# Sky130 3 BIT SAR ADC
This a project I first started over my summer to learn more about mixed signal systems and how both analog and digital signals intersect! I originally was interested in the idea as our world fully consists of varying signals 
however the technology we use and develop live off of ones and zeros. At the moment I am still updating the project, but I want the end product to seamlessly convert an analog signal to a 3 bit digital signal. This repository
will showcase my current work but also will document what I will create in the future. I used xschem, sky130 pdk, systemverilog and python.
